**굴곡진 큰 폐곡선의 전체 형태 자체가 안쪽에서도 여러 겹 반복되어야 한다.**

- 판정 기준: `qa/renders/approved-repetition-reference.png` — 사용자가 제공한 「삼색 직조 공명 바이닐(1).png」.
- SHA256: `be889493982f41b186426f42266b8107bdaa8b1c072f943fb0232502edc32e4b`.
- 한 띠의 폭만 채우기, 국부 고리 추가, 동심원, 균등한 3개 층으로 쌓기는 요구 충족이 아니다.

- 먼저 한 색의 한 겹/두 겹/여러 겹을 실제 렌더에서 확인한다. 이 형태가 맞기 전 색·입자 추가를 진전으로 대신하지 않는다.
- 2D→3D에서 같은 선의 대응이 유지돼야 한다. 중간 형태의 중심 붕괴도 실제로 확인한다.

## 4. 최신 검증과 한계

- 추가 진단: 큰 굴곡(k=1..3)에도 선별 위상을 적용해 실제 Chromium으로 한 겹/두 겹/24겹을 확인했다. 교차는 생겼으나 여전히 한 띠로 보여 **시각 판정 실패**. 이 단일 원인 수정만으로는 요구를 충족하지 못한다. console/JS 오류 0, 생성된 4개 레이어의 XZ 끝점 차이 0. 새 전환·오디오·모바일·장시간 검증 통과를 뜻하지 않는다. 캡처: `/review/low-frequency-diagnostic.jpg`.
- 배포 빌드에서 `build-candidate.mjs`도 실행하도록 연결해 후보 소스와 배포 HTML이 따로 남지 않게 했다. 기본 복구 HTML 및 기준 이미지 SHA256은 위 기록과 일치한다.

- 배포 점검에서 `b9437d0` 이후 문서 갱신 커밋의 원격 tree에 기존 파일이 누락된 오류를 발견했다. commit SHA를 base tree로 잘못 전달한 것이 원인이었다. 정상 `6055b92`의 실제 tree를 기준으로 파일을 보존하고 이번 변경만 추가했다. 기존 파일의 의도치 않은 변경·누락 0건을 전체 tree 대조로 확인했다. 실패 배포 `53f3fb1`은 최종 결과로 사용하지 않는다.

- 복구본: analysis/geometry **48개**, 실제 Chromium browser **39개** 통과. console/JS 오류 0.
- 단색 후보: 실제 WebGL 한 겹/두 겹/24겹 캡처 확인. console/JS 오류 0.
- 후보 4개 레이어의 2D/3D 끝점 XZ 차이 0: 중심을 가로질러 보간하던 원인을 제한적으로 제거했음을 확인한 수치다. 전체 전환 품질 통과를 뜻하지 않는다.
- 원본과 실제 렌더 비교 결과 **시각 판정 실패**. 선 수·폐곡선·자동 적합값·테스트 통과를 시각 완성 근거로 사용하지 않는다.
- 후보의 입자·보컬별 차이·2–4명 합성·실제 오디오·모바일·장시간 안정성은 새 구현에 대해 완료 검증하지 않았다.

## 5. 다음 시작 지점 / 남은 조건

1. 원본의 큰 굴곡 순서를 가진 **별도의 안쪽 전체 폐곡선**을 직접 식별하고 원본 위에서 비교한다. 현재 반경 추적/일괄 적합 후보를 성공 모델로 확장하지 않는다. 한 띠로 붙는 구간부터 해결한다.
2. 한 색의 전체 형태 반복이 맞으면 2D→3D 중간 렌더의 대응·교차·중심 붕괴를 확인한다.
3. 그 뒤 색별 자연스러운 직조·교차·접힘과 선/입자 질감을 개선한다. 파랑·코랄·크림 모두 입자를 사용하고 크기·밀도 차이를 보존한다.
4. 개인별 보컬 차이·동일 입력 재현성·2–4명 합성·바이닐 연결·실제 오디오 반응·재생 전후 모션을 검증한다.
5. 390px 모바일 뭉침, 실제 브라우저 회귀, 장시간 안정성을 검증한다.
6. 매 실행 종료 시 이 문서의 현재 상태를 갱신하고 commit/push 및 Preview 링크를 제공한다. 다음 진행 여부를 묻지 않는다.
