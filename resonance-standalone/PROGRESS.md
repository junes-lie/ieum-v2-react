# IEUM Resonance — 현재 작업 상태

최종 갱신: 2026-10-20 KST. **최신 사용자 결정: 2D·3D 모두 색마다 한 겹으로 통일. 선과 입자를 함께 사용한다. 시각 완성 승인은 아직 없다.**

## 1. 현재 작업본

- `/repetition-candidate.html?repetition=1&composite=1`: 세 색 합성. 각 색은 하나의 부모 폐곡선 안에 12개 선과 입자로 구성된다. 색별 보기·대표 곡선/선과 입자·2D↔3D·오디오 조작 제공.
- 한 겹은 “선 한 줄”이 아니다. 동일한 큰 경로 안의 내부 결과 입자는 유지한다.
- `/IEUM-Resonance.html`: 기존 복구 실행본. 이번 변경 범위 밖.
- 예전 파랑 단독 비교·후보 링크는 역사적 비교 자료이며 최신 작업 시작점이 아니다.

## 2. 최신 사용자 결정

- 15:09의 세 색 안팎 두 폐곡선 지시는 **17:50 지시로 대체됐다**: “둘이 다를수는 없지 않음? 통일시켜야지 전환이 되지 그냥 한겹으로 하자”.
- 2D와 3D에서 서로 다른 겹수로 바꾸거나, 전환 중 두 경로를 하나로 합치는 방식을 적용하지 않는다. 같은 선의 x/z 경로를 유지하고 높이와 카메라로 전환한다.
- 세 색의 다른 보컬 특성·굴곡·선/입자 성격은 보존한다. 파랑·코랄·크림을 같은 곡선으로 복제하지 않는다.
- 픽셀 추적·새 조형 후보 탐색을 재개하지 않는다. 꽃·별·면·재질·튜브 금지.
- 교차와 자연스러운 혼합·펼쳐짐/모임·선에 따르는 입자는 여전히 개선 대상이다. 겹수만 바꿔 시각 완성이라고 판정하지 않는다.

## 3. 이번 변경

- 기준 HEAD `f018926`.
- composite 모드는 실제 기하를 색당 24선(12선×2회)에서 **12선×1회**로 변경했다. 안쪽 반복 생성과 두 경로 표시 조작을 제거했다.
- 파랑은 기존 바깥 부모 경로의 12선을 사용한다. 코랄·크림은 각각 기존 바깥 부모 경로를 한 번 생성한다.
- 기본 화면은 내부 여러 선과 입자 켜짐이다. 이전 “대표선 여섯 개·입자 꺼짐” 기본값을 폐기했다.
- 2D와 3D의 x/z 대응 구조를 유지했다. 3D만 겹수를 줄이려던 미배포 수정은 채택하지 않았다.

## 4. 검증과 한계

- `IEUM_VALIDATE_GEOMETRY=1 node build-candidate.mjs`: 세 색 각 12선, 폐곡선 닫힘, 유한 좌표, 동일 입력 재현성 통과. 기존 빌드도 성공.
- 반경 범위: 파랑 1.510–2.296, 코랄 1.637–2.470, 크림 1.562–2.314.
- 브라우저 회귀 QA `qa/composite.cjs`를 한 겹 기준으로 변경했다. **이번 실행에서는 수행하지 못했다.** 기존 Chromium 실행 파일이 없고, 공식 headless-shell 설치도 ZIP 다운로드 오류(`End of central directory record signature not found`)로 실패했다.
- 따라서 이번 수정의 실제 2D/중간/3D 렌더·모바일·입자 모양을 확인했다고 주장하지 않는다. 배포 빌드 성공과 실제 시각 검증을 구분한다.
- 실제 오디오·2–4명·장시간 안정성의 최종 통합 검증도 남아 있다. 자동 실행은 이전에 일시중지됐으며 이번에 변경하지 않는다.

## 5. 다음 시작 지점 / 범위

1. 최신 한 겹 합성본에서 실제 렌더를 먼저 확인한다. 예전 두 겹 또는 2D 두 겹/3D 한 겹으로 돌아가지 않는다.
2. 같은 경로를 유지하며 교차부의 깊이·선 밀도·펼쳐짐/모임과 색별 입자를 개선한다.
3. 선/입자·2D↔3D·실제 오디오·2–4명·재현성·장시간 안정성을 검증한다.
4. `feature/resonance-standalone`의 `resonance-standalone/`만 수정한다. main·기존 React 앱·Production·Notion·Figma는 변경하지 않는다. Computer Use 금지.
5. 매번 원격 HEAD를 확인하고 기대 SHA로 갱신한다. 다른 실행의 변경을 덮지 않는다. 수정 결과는 Preview로 전달한다.
6. 복구가 필요할 때만 `qa/recover-polish.mjs`와 `qa/recovery-polish.json`의 해시를 검증한다. 이번에 복구하지 않았다.
