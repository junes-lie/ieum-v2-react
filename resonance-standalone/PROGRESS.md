## 시각적으로 개선한 부분

1. 균등 38줄의 막 같은 표현을 줄이고 24줄의 비균일 흐름과 여백으로 수정.
2. 픽셀 선 두께/가장자리 조정으로 작은 렌더에서 끊겨 보이던 선 개선.
3. 실제 depth write/test로 선 교차 앞뒤를 표현. 개인 SVG에도 깊이 기반 가림 사용.
4. A에 뒤쪽 고리를 살리고 B의 조밀한 교차, C의 높은 고리와 국부 봉우리, D의 비대칭 접힘을 구별.
5. 입자 개수/흐름 증가, 가까운 다른 경로의 접촉장에서 폭과 속도 변화.
6. 에너지에 시간 전체를 곱하던 입자 위치 계산을 누적 위상으로 수정하여 속도 변경 시 위치 점프 제거.
7. 재생 시 실제 대역별 국부 변위, 일시정지 시 지수 감쇠. 전체 회전/확대만으로 대체하지 않음.

## 남은 차이 / 한계

- 기준 시안의 세밀하고 비정형적인 미세 접힘·선 두께·산포를 완전히 재현하지 못함. 현재 결은 더 규칙적이며 일부 각도에서는 다발이 판처럼 읽힐 수 있음. **최종 시각 품질 완료로 판정하지 않음**.
- 개인 SVG의 가림은 근접도 기반 근사이며 모든 촬영 각도의 3D 교차를 표현하는 모델이 아님.
- 합성은 경로 근접도 기반 관계이며 물리적 실 매듭/충돌 해석이나 실제 보컬 상관도 분석이 아님. 참여자 변경 시 접촉장 폭의 국부 변화는 즉시 적용됨.
- 제공된 실제 사람 보컬 샘플이 없음. 생성 WAV로 DSP 동작을 검증했으며 음색 인지 타당성/동일인 다른 녹음 일관성은 미검증.
- 프로젝트 voiceIdentityContract / AI 추론 / 제출된 Track 정책과 직접 연결하지 않음. 독립본의 특성 proxy를 제품의 검증된 음색 판정으로 간주하지 않음.
- 실제 휴대폰/데스크톱 GPU, Safari/Firefox, 실제 청취 검증 미실시.
- 파일/프로필은 메모리 상태. SVG/JSON 내보내기는 가능하지만 JSON 다시 불러오기는 없음.

## 실패 원인과 접근 변경

- 메모리 회귀 검사가 새 geometry가 GPU에 업로드되기 전에 읽어 10→4로 실패: 임의 200ms 대기 대신 실제 렌더 후 geometry 수를 기다리도록 검사 수정.
- pause 시 RMS와 FFT 감쇠 상수가 다른데 RMS만 기다리고 검사하여 실패: 양쪽 상태의 감쇠를 실제 기다리도록 수정.
- SwiftShader에서 전체 화면/모달 캡처를 기능 검사와 병행할 때 지연과 검은 캡처 발생. 중간 결과는 최종 근거로 사용하지 않음. 캡처와 기능 검사를 분리하고, 매듭 영역 중심의 전용 캡처 및 별도 개인 SVG 렌더를 사용. 불필요한 모달 backdrop blur 제거.
- 이러한 실패를 도형 품질 통과로 처리하지 않았음. 중간 캡처는 Git 저장에서 제외.

- 최종 회귀 중 입자 geometry NaN 경고 발견. 초기 RAF timestamp의 음수 dt 가능성을 차단하고 접촉장 위상 조회를 항상 양의 주기로 보정. 재구성 후 모든 입자 위치/위상 유한성 검사를 추가해 재검증.

### 최신 소스 수정 복구

최신 세 소스 파일의 정확한 변경을 `qa/recovery-polish.json`에 저장했다. 원본/결과 Git blob SHA를 검사하는 `qa/recover-polish.mjs`도 포함했다. 이 복구 도구 자체는 실행기 장애 때문에 실행하지 못했으며, 모든 치환이 원격 기준 파일에서 정확히 한 번 매칭되고 결과 blob이 생성되는 것까지 확인했다.

1. 최신 브랜치와 이 문서를 확인한다.
2. `node qa/recover-polish.mjs` — 기준 파일에 다른 변경이 있으면 중단하며 덮어쓰지 않는다.
3. `npm ci && npm run build && npm test`.
4. 생성 HTML 해시를 위 로컬 수정본 해시와 비교하고, 브라우저 39개 회귀 검사를 다시 실행.
5. `qa/capture.cjs`로 실제 렌더를 재생성. 정지 캡처는 readback 동안 추가 draw만 멈추며 모션 검증과 구분.
6. `qa/motion.cjs`로 실제 캔버스/오디오 WebM 재생성. MP4가 필요하면 FFmpeg로 `-vf fps=30 -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p -c:a aac -movflags +faststart` 변환. 움직임 보간은 하지 않음.
7. 최종 10분 연속 검증을 새로 완료하고 결과·시각 차이를 기록한 뒤 commit/push 및 원격 확인.
8. Phase 6의 미세 결 차이와 실제 사람 보컬/실기기 미검증을 해결하기 전 전체 DoD 완료로 표시하지 않는다.

기존 React 앱, main, Notion, Figma, Vercel Production은 이 작업에서 수정하지 않았다.
