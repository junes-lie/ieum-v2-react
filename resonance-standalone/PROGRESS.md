## 2. 우선 구현할 요구

**2026-10-20 15:09 KST 사용자 정정이 우선한다: “노랑 빨강도 안쪽바깥쪽으로 두 폐곡선”. 범위를 넓히는 것만으로 대체하지 않는다. 각 색마다 같은 부모 경로의 굴곡·접힘을 공유하는 바깥/안쪽 두 경로, 세 색 총 여섯 경로로 합성한다.**

**굴곡진 큰 폐곡선의 전체 형태 자체가 안쪽에서도 여러 겹 반복되어야 한다.**

**파랑은 한 사람이다. 바깥·안쪽은 같은 보컬 특성과 같은 형태 생성 규칙의 반복이어야 한다.** 크기·간격이 달라도 큰 굴곡의 순서, 접힘 방식, 선·입자의 성격이 이어져야 한다. 바깥·안쪽을 독립적인 형태로 만드는 것은 요구 위반이다. 같은 색을 쓰거나 둘 다 폐곡선이라는 이유로 동일 인물로 판정하지 않는다. 원본을 무시한 일괄 축소도 정답으로 간주하지 않는다.

- 판정 기준: `qa/renders/approved-repetition-reference.png` — 사용자가 제공한 「삼색 직조 공명 바이닐(1).png」.
- SHA256: `be889493982f41b186426f42266b8107bdaa8b1c072f943fb0232502edc32e4b`.
- 한 띠의 폭만 채우기, 국부 고리 추가, 동심원, 균등한 3개 층으로 쌓기는 요구 충족이 아니다.
- 원본 위에 겹쳐 큰 굴곡과 안쪽 전체 곡선의 관계를 비교한다. 가려진 구간은 추정으로 표시한다.
- **최신 사용자 지시에 따라 코랄도 바깥/안쪽 두 경로로 구현한다.** 이전 파랑 단독 검증 순서는 최신 합성 지시로 대체됐다. 파랑 두 경로를 보존하면서 코랄·크림과 합성한다.
- 2D→3D에서 같은 선의 대응이 유지돼야 한다. 중간 형태의 중심 붕괴도 실제로 확인한다.

## 4. 최신 변경과 검증

- 기준 HEAD `a49a2e6`. 사용자가 지적한 단순 반경 확대 구현을 수정했다.
- 파랑은 기존 부모 경로·190px 안쪽 이동을 그대로 유지한다. 노랑/빨강은 각 색의 기존 baselinePlanar를 12개 로컬 선으로 생성하고, 그 전체 부모 경로를 안쪽에 한 번 더 반복한다. 두 그룹은 같은 t·로컬 선 번호·굴곡·각도·3D 높이를 공유한다.
- 코랄 반경 이동 0.78, 크림 0.72. 바깥/안쪽을 독립 생성하지 않는다. 노랑/빨강의 경로를 파랑과 같은 형태로 복제하지 않는다.
- 기본 화면에서 각 색의 대표 바깥/안쪽 경로, 총 여섯 폐곡선을 표시한다. “각 경로의 여러 선”으로 12선씩 두 그룹 표시 가능. 입자는 기본 꺼짐이며 기존 토글로 켤 수 있다.
- `qa/composite.cjs`: 파랑의 기존 평면 좌표 보존, 세 색의 안팎 반경차·방향·높이 대응, 합성/단색 전환, 1100px/390px의 2D/중간/3D 캡처와 JS 오류 검사.
- 기준 이미지 완전 일치·최종 시각 승인은 주장하지 않는다. 실제 오디오·장시간 안정성은 이번 검증 범위가 아니다.

이전 실행의 Chromium 차단은 현재 환경에 해당하지 않는다. 현재 실행은 기존 Chromium으로 실제 렌더 검사를 수행한다. 자동 실행은 이전 실행에서 일시중지된 상태이며 이번 수동 수정에서 변경하지 않는다.
