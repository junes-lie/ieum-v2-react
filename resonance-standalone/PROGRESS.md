## 2. 우선 구현할 요구

**굴곡진 큰 폐곡선의 전체 형태 자체가 안쪽에서도 여러 겹 반복되어야 한다.**

- 판정 기준: `qa/renders/approved-repetition-reference.png` — 사용자가 제공한 「삼색 직조 공명 바이닐(1).png」.
- SHA256: `be889493982f41b186426f42266b8107bdaa8b1c072f943fb0232502edc32e4b`.
- 한 띠의 폭만 채우기, 국부 고리 추가, 동심원, 균등한 3개 층으로 쌓기는 요구 충족이 아니다.
- 원본 위에 겹쳐 큰 굴곡과 안쪽 전체 곡선의 관계를 비교한다. 가려진 구간은 추정으로 표시한다.
- **반복 구조 확인 대상은 파랑부터, 이어서 크림이다. 코랄은 원본에서 같은 두 겹 구조가 아니므로 코랄 실험을 반복 구현의 기준으로 삼지 않는다.** 먼저 파랑의 바깥/안쪽 전체 경로를 실제 렌더와 원본에서 확인한다. 이 형태가 맞기 전 색·입자 추가를 진전으로 대신하지 않는다.
- 2D→3D에서 같은 선의 대응이 유지돼야 한다. 중간 형태의 중심 붕괴도 실제로 확인한다.

## 4. 최신 검증과 한계

- 2026-10-20 후속 진단: `correspondence-audit.mjs`로 기존 파랑 바깥/안쪽 각 12선의 반경 순서 교환이 **각각 0회**임을 확인했다. 고정 분위수와 양의 평활화가 순서를 보존하므로 선 수·두께 변경만으로 원본 직조를 만들 수 없다.
- `?repetition=1&rankWeave=1`은 같은 두 성분 경계 안에서 선의 순서를 바꾸는 **기각 진단**이다. 실제 렌더에서 교차는 생겼지만 규칙적 격자에 가까워 원본 접힘 미충족. 기본 파랑 비교본과 복구 runtime은 유지했다. Chromium에서 2D/중간/3D/390px 렌더, XZ 대응 drift=0, JS·console 오류 0을 확인했으며 시각 승인과 구분한다.
- 모바일 QA 정정: 데스크톱 페이지를 390px로 resize한 기존 검사에서 PNG가 1028px로 남는 오류를 발견했다. 새 390px 페이지에서 366px stage를 직접 캡처하고 PNG 너비를 검사하도록 `verify.cjs`를 수정했다. 새 실제 모바일 캡처에서도 선 밀집은 남아 있다. 과거 resize 캡처만으로 모바일 검증 성공을 판단하지 않는다.
- 다음 작업은 이 진단의 위상·선 수 튜닝이 아니다. 원본의 교차 지점 전후 선 방향을 따라 연결 관계를 추적하고, 각도당 반경 하나인 표현으로 원본의 되접힘을 표현할 수 있는지 먼저 확인한다. `paths.json`은 경계 관측 자료이며 개별 실의 정답이 아니다.

- 파랑 실제 Chromium 검증: 바깥/두 전체 경로/24개 선, 2D·중간 전환·3D·390px 캡처. JS/console 오류 0, 실제 표시 프로필 A(BLUE), 입자 OFF. 선 두 성분 사이를 채우는 경로는 생성하지 않는다.
- 생성한 4개 레이어의 2D/3D XZ 끝점 차이 0, 최소 반경 약 0.689. 비교본 라벨은 원본 비율에 가깝게 0.60으로 조정했다. 기본 라벨/조형은 유지한다.
- 실제 중간·3D 렌더에서 두 성분이 중심으로 가로질러 이동하는 현상은 관찰하지 않았다. 원본의 굽힘·직조 질감 일치, 사용자 시각 승인, 크림 확장, 입자·보컬 합성 검증을 뜻하지 않는다.
- 이전 코랄/큰 굴곡 위상 진단은 실패 이력으로 보존한다. 이를 새로운 반복 구현의 기준으로 재활성화하지 않는다.

- 복구본: analysis/geometry **48개**, 실제 Chromium browser **39개** 통과. console/JS 오류 0.
- 원본과 비교하면 파랑의 두 전체 성분은 구분되지만 현재 각 성분 내부는 나란한 선에 가까워 원본의 교차·접힘 결이 부족하다. 선 수·폐곡선·자동 검사만으로 시각 완성 판정하지 않는다.
- 후보의 입자·보컬별 차이·2–4명 합성·실제 오디오·모바일·장시간 안정성은 새 구현에 대해 완료 검증하지 않았다.

## 5. 다음 시작 지점 / 남은 조건

1. 파랑 원본 위 경로와 실제 두 전체 경로를 대조해 큰 굴곡과 안쪽 반복의 관계를 확인한다. 현재 관측 구간의 분위수 추적은 원본의 개별 선을 복원한 것이 아니다. 각 성분에서 원본의 자연스러운 교차·접힘을 따라 이어지는 선 대응을 개선한다. 단순 평행 띠를 완성으로 삼지 않는다. 이어 크림의 반복 구조를 같은 방식으로 확인한다.
2. 한 색의 전체 형태 반복이 맞으면 2D→3D 중간 렌더의 대응·교차·중심 붕괴를 확인한다.
3. 그 뒤 색별 자연스러운 직조·교차·접힘과 선/입자 질감을 개선한다. 파랑·코랄·크림 모두 입자를 사용하고 크기·밀도 차이를 보존한다.
4. 개인별 보컬 차이·동일 입력 재현성·2–4명 합성·바이닐 연결·실제 오디오 반응·재생 전후 모션을 검증한다.
5. 390px 모바일 뭉침, 실제 브라우저 회귀, 장시간 안정성을 검증한다.
6. 매 실행 종료 시 이 문서의 현재 상태를 갱신하고 commit/push 및 Preview 링크를 제공한다. 다음 진행 여부를 묻지 않는다.
