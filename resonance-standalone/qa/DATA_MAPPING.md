# 데이터와 표현의 연결

## 현재 독립 실행본

|입력|방법 / 한계|개인 매듭|바이닐 위 공명|
|---|---|---|---|
|pitch|Pitchy 단성음 F0 중앙값, 85–650 Hz 로그 정규화. 음역 한계 아님|넓이/높이 비율, 루프 비중|국부 높이, 봉우리 폭|
|brightness|FFT 스펙트럼 중심의 중앙값, 로그 정규화|교차의 조임, 굴곡|세부 굴곡 수/폭|
|air|피치 명료도와 spectral flatness의 혼합 proxy. 실제 breathiness 판정 아님|입자 비율, 선 퍼짐|입자 개수/퍼짐|
|phase|위 세 값으로 결정, 난수나 ID 기반 아님|비대칭 굴곡 위치|높이·교차 위치|
|실시간 RMS|개별 AudioBuffer → 개별 AnalyserNode|정적 기본 형태 보존|국부 변위와 흐름 속도|
|60–300 / 300–1800 / 1800–8000 Hz|실제 FFT 대역 크기, 인지적 음색 분류 아님|기본 형태 보존|높낮이 / 굽힘 / 잔결|
|RMS 상승|단기 상승량 proxy. BPM/박자 검출 아님|기본 형태 보존|짧은 국부 굴곡|

파일 분석 성공 후에만 프로필과 오디오를 함께 교체합니다. 침묵·잡음·잘못된 파일은 기존 데이터를 유지합니다. 같은 녹음의 분석/기본 도형은 재현되지만, 같은 사람이 다른 환경에서 녹음해도 같은 도형이 된다는 생체 식별 보장은 없습니다. 유사한 정규화 특성은 유사한 도형이 됩니다.

## 실제 프로젝트 계약과의 관계

읽은 `src/voiceIdentityContract.js`는 brightness / roughness / dynamics를 측정 proxy로 허용하고 여러 후보를 unsupported로 표시합니다. `src/voiceVisualMapping.js`는 잠정 엔지니어링 매핑입니다. 독립본의 pitch / air 필드를 이 제품 계약의 확정 필드로 사칭하지 않습니다. 아직 제품 snapshot을 직접 import하거나 AI 추론 서비스를 호출하지 않습니다.

A/B/C/D는 **설계용 데모 프로필**, 기본 재생음은 **합성된 테스트 신호**입니다. 사용자가 올린 보컬 파일은 실제 신호에서 추출합니다. 실제 사람들의 검증용 녹음 자료는 제공되지 않았고, 합성 WAV 검사로 음색의 인지적 타당성을 입증할 수 없습니다.

## 합성

개인 매듭과 레코드 흔적은 동일한 descriptor를 사용하는 별도 함수입니다. 개인 아이콘의 선 한 겹을 떼어 레코드에 복사하지 않습니다.

개인의 닫힌 중심 경로는 다른 참여자 수에 의존하지 않습니다. 각 경로에서 다른 활성 경로까지의 거리를 샘플링하여 부드러운 접촉장을 만듭니다. 가까운 곳에서 선 다발이 좁혀지고 입자가 감속하여 밀도가 생깁니다. 단순 alpha 중첩보다 관계를 추가하지만, 물리적인 실 충돌 시뮬레이션이나 보컬 간 실제 상관도 분석은 아닙니다. 참여자 추가 시 기존 경로와 누적 입자 위상을 보존합니다. 변화하는 접촉장의 폭은 즉시 갱신되어 작은 국부 변화가 남습니다.

## 렌더링

Three.js WebGL: 화면 픽셀 두께의 선 quads + point sprites. 선 표현을 위한 삼각형은 화면 공간 래스터화 수단이며, 물체 표면/리본/튜브를 렌더하지 않습니다. 선의 depth test/write로 실제 앞뒤를 구분합니다. 개인 SVG는 곡선 깊이와 근접도 기반 가림을 사용합니다. 바이닐 바탕은 물체지만 색상 매듭에는 재질/조명 면을 사용하지 않습니다.
